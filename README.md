# StudentConsoleApp - Gasoline Station Management System (Deliverable 8)

Open in IntelliJ: File > Open > select the `StudentConsoleApp` folder (pom.xml) > "Trust Project".
Make sure Project SDK is Java 17+. Run `com.yourdomain.Main`.

Default admin: `admin` / `admin123`. `students.db` is created automatically on first run.

Rename the package `com.yourdomain` to your group's package
(right-click package > Refactor > Rename) and update groupId in pom.xml.
